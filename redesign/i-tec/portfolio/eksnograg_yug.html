Задача заказчика

Необходимо реализовать комплексное мультимедийное решение для конференц-зала. Основной целью данного решения является создание современного мультимедийного пространства для проведения различного рода конференц-мероприятий. Основную задачу, которую должен выполнять комплекс оборудования – отображение видеоматериала на большом экране в сочетании с качественным звуковым сопровождением мероприятий, возможностью упорядоченного выступления участников конференции с помощью оборудования для усиления речи выступающих и записью и трансляции мероприятий.

Выполненные работы

Специалистами ГК Айтек был успешно завершён проект по комплексному оснащению объекта современным мультимедийным оборудованием под ключ. В ходе реализации проекта был произведён весь спектр работ — от поставки оборудования и разработки проектной документации до финальной отладки систем. Состав реализованного комплекса: Проектор с мощностью светового потока 10000 люмен Проекционный экран 2.59 х 4м с электроприводом Интерактивная трибуна для выступлений спикера Звуковые линейный массивы, состоящие из 2-х ВЧ и СЧ элементов Конференц-система для интерактивного взаимодействия во время семинаров и групповых сессий Театральное и профильное освещение сцены Скрытая многоуровневая коммутация Централизованное управление всем оборудованием с единого пульта
