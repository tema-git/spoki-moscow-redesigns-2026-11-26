Задача заказчика

ГК Айтек приняла участие в комплексном мультимедийном оснащении аэропорта Петрозаводск. Основной целью проекта было создание мультимедийного пространства для возможности отображения справочно-развлекательного контента на информационных видеопанелях по периметру всего аэропорта. Также, необходимо было реализовать зональное озвучивание помещений для оповещения посетителей аэропорта.

Выполненные работы

Специалистами ГК Айтек был успешно завершён проект по комплексному оснащению объекта современным мультимедийным оборудованием под ключ. В ходе реализации проекта был произведён весь спектр работ — от поставки оборудования и разработки проектной документации до финальной отладки систем. Состав реализованного комплекса: Размещение более 20 дисплеев по периметру аэропорта Установка специализированного ПО FIDS для централизованного распределения контента Фоновое озвучивание центрального холла Фоновое озвучивание ресторана и кафе Фоновое озвучивание смежных коридоров Фоновое озвучивание конференц-зала Централизованное управление всем оборудованием с единого пульта
