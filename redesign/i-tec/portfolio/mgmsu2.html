Задача заказчика

Заказчик поставил задачу создать многофункциональное пространство для мероприятий и ВКС с качественной визуализацией, гибким управлением контентом, четким звуком, автоматической трансляцией выступающих, скрытым монтажом без нарушения интерьера и единым интуитивным пультом управления. Критично — реализация под ключ с разработкой документации, монтажом и отладкой в сжатые сроки с гарантией бесшовной работы всех подсистем.

Выполненные работы

Специалистами ГК Айтек был успешно завершён проект по комплексному оснащению объекта современным мультимедийным оборудованием под ключ. В ходе реализации проекта был произведён весь спектр работ — от поставки оборудования и разработки проектной документации до финальной отладки систем. Состав реализованного комплекса: Светодиодный экран 1,9 х 3,8м с шагом 1,25мм Дополнительная интерактивная панель 86″, дублирующая изображение главного экрана Индивидуальный дублирующий монитор 27" для президиума Индивидуальные интерактивные планшеты 11" для делегатов Интерактивная трибуна для выступлений спикера Звуковые линейный колонны Камеры захвата с умным наведением на активного спикера Потолочные микрофонные массивы для участия в ВКС Система скрытой коммутации кабельных линий в условиях готовой чистовой отделки помещения Централизованное управление всем оборудованием с единого пульта
