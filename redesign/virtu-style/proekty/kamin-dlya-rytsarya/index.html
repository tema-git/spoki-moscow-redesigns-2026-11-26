2015 год, Апрель

Камин для рыцаря

Смета проекта:

Каминная топка VIRTU VK - 270 т.р.

Вороненая фасадная плита с болтами - 90 т.р.

Трехсторонняя топка панорамного вида, открытая с одной стороны, изготовлена под заказ.

Суммы и условия относятся к проекту 2015 года.

Размеры: 860х450мм, не стандартно не большого размера глубина – 500мм (все размеры на чертежах в приложении письма)

Материал: металл

Цвет: черный

Покрытие: огнеупорная краска черного цвета

Комплектация камина:

топка(цельная конструкция на ножках)

огнеупорные, прозрачные стекла. Одно стекло открытое, два глухих.

зольником для сбора золы

колосниковая решетка из высокопрочной 1.2см стали (на нее кладутся дрова)

шибер (небольшая черная ручка в углу) для регулирования выхода газа при горении

портал, железо с эффектом воронения

Этапы монтажа камина

Установка топки – топка распаковывается и устанавливается в нишу, прилегание топки к стене не плотное, остается технический зазор около 5 мм, для лучшей усадки топки

Сверху одевается дымоход

Крепятся стекла. Сначала два боковых стекла, которые являются стационарными. После этого аналогично крепиться центральное стекло..

В нижней части топки устанавливается зольник для сбора продуктов горения (золы)

Сверху зольника устанавливаются колосниковые решетки. Состоят из трех независимых решеток, для облегчения эксплуатации. На них приходиться основная температурная нагрузка (горят дрова), поэтому они изготавливаются из стали толщиной 1.2 см.

Установка декоративного портала. Портал изготовлен из железа, которое подверглось специальной обработке «Воронение». Данная технология применяется для изготовления оружейной стали.

Работа топки

Внизу топки есть специальные отверстия для забора воздуха, который необходим для процесса горения. Воздух проходит через колосниковую решетку, непосредственно к топливу.

Так же процесс горения регулируется шибером, который устанавливается заранее, при изготовлении топки. Шибер обеспечивает регулировку выхода газов, которые образуются при горении топлива, при повороте ручки шибера отверстие дымохода или увеличивается или уменьшается. При увеличении отверстия, увеличивается тяга, данное положение характерно при активном горении дров. При уменьшении отверстия, тяга так же уменьшается, данное положение при тлении углей позволяет использовать камин для обогрева помещения.

Портал

Портал представляет собой лист металла, который подвергался процессу воронения (обрабатывался специальным составом). Воронение металла – это технология которая применяется при изготовлении оружейной стали. После этого портал покрывался термозащитным матовым лаком, для облегчения эксплуатации. Все болты, которые присутствуют на декоративной внешней части, изготовлены вручную.
